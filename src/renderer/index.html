Conecte sua conta LG

Este app usa a API oficial da LG. Ela pede um token pessoal, gerado uma vez com a mesma conta do app ThinQ.

  1. Abra a página de tokens e entre com sua conta LG.
  2. Crie um token marcando as três permissões: ver aparelhos, ver status e controlar aparelhos.
  3. Copie o valor do token e cole abaixo.

O token fica salvo só neste computador, criptografado pelo sistema.
